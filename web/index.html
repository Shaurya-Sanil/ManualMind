    Natural Language Processing Laboratory

    Interactive verification tools mirroring every syllabus concept, comparing from-scratch implementations with reference libraries.

    1. Tokenization Comparison

    Tokenization is the foundational process of segmenting text into discrete linguistic units (tokens). Different paradigms include character-level, whitespace/regex (NLTK), linguistic neural models (spaCy), subword WordPiece (BERT), and Byte Pair Encoding (BPE) learned iteratively from pair frequencies.

    2. Stopword Removal & Text Statistics

    Stopwords are high-frequency grammatical functional words (articles, prepositions) that carry low semantic discrimination in bag-of-words retrieval. Removing them alters vocabulary density, token counts, and retrieval precision.

    3. Stemming vs Lemmatization

    Stemming strips inflectional affixes using heuristic rule cascades (Porter, Lancaster), often producing non-lexical stems. Lemmatization leverages morphological vocabularies and POS context (WordNet, spaCy) to reduce inflected forms to their canonical dictionary lemma.

    4. Regular Expression Technical Pattern Extraction

    Deterministic regular expressions extract formal technical tokens: error codes (E-101), MAC addresses, IP addresses, frequencies (5 GHz), voltages (12 V), and menu navigation breadcrumbs (Settings > Network > Wi-Fi).

    5. Levenshtein Edit Distance & Dynamic Programming Matrix

    Minimum edit distance finds the least number of insertions, deletions, and substitutions to transform source word S into target word T. The dynamic programming matrix tabulates subproblems D(i, j), and backtracing computes the optimal operation sequence.

    6. N-Gram Language Modeling & Perplexity

    N-gram models predict the probability of word w_i conditioned on the preceding (n-1) words using maximum likelihood estimation. Laplace add-1 smoothing prevents zero probabilities, and perplexity measures the model's surprise on held-out text.

    7. Part-of-Speech Tagging Side-by-Side

    Compares 4 POS tagging paradigms: (a) Rule-based regex tagger, (b) Hidden Markov Model (HMM) with Viterbi decoding implemented from scratch, (c) Conditional Random Field (CRF) discriminative sequence model, (d) spaCy neural tagger.

    8. Syntactic Chunking (NP & VP)

    Chunking segments sentences into non-overlapping syntactic phrases. NLTK RegexpParser applies regular expressions over POS tags to identify Noun Phrases (NP) and Verb Phrases (VP).

    9. Named Entity Recognition (NER)

    Extracts domain-specific entities (COMPONENT, ERROR_CODE, SETTING, PRODUCT, MEASUREMENT, ACTION) comparing rule-based gazetteers, CRF sequence labeling, and general BERT transformer models.

    10. TF-IDF Term-Document Matrix & Cosine Similarity

    Constructs an explicit term-document matrix from scratch using tf(t, d) * idf(t) and ranks chunks with cosine similarity. Validated against scikit-learn TfidfVectorizer.

    11. Word2Vec Static Word Embeddings

    Learns continuous distributed representations of words using Word2Vec Continuous Bag-of-Words (CBOW) and Skip-gram architectures trained directly on the manual text.

    12. Sparse vs Dense Feature Vector Representations

    Contrasts high-dimensional sparse feature vectors (exact one-hot indicators for words, bigrams, and prefixes) against continuous 384-dimensional dense semantic embeddings.

    13. Intent Classification Comparison

    Compares pure NumPy Multinomial Naive Bayes (log-priors + Laplace smoothed likelihoods) against Scikit-learn Logistic Regression across 7 customer support intent classes.
